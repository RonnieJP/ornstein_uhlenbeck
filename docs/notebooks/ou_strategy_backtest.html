1 Ornstein Uhlenbeck Spread Backtest

In order to show that the OU process can be applied to pairs trading we will first construct a synthetic spread and then move to real life data. For real pairs, we first investigate a linear spread, given two asset price series. We then fit the OU model to the observed spread.

1.1 Backtest on Synthetic Spread

Let us generate an OU process and treat it as if it were an observed spread.

Take \(\theta = 2, \mu = 0, \sigma = 1\).

Code 
import ornstein_uhlenbeck.ou as ou
import numpy as np
import plotly.graph_objects as go
import plotly.io

params = ou.OUParams(
    theta = 2.0,
    mu = 0.0,
    sigma = 1.0
)

x0 = 0.0
dt = 0.01
n_steps = 1000
n_paths = 1

rng = np.random.default_rng(42)

t = ou.time_grid(dt, n_steps)
path = ou.simulate_paths(x0, params, dt, n_steps, n_paths, rng)

def apply_theme(fig):
    fig.update_layout(

    )
    return fig

fig = go.Figure()
fig.add_trace(
    go.Scatter(
        x = t,
        y = path[:,0],
        name = "Simulated path",
        mode = "lines",
    )
)

fig.add_hline(
    y = params.mu,
    line_dash = "dash",

)

fig.update_layout(

)

apply_theme(fig)
fig.show()

We will now devise a trading rule. For the synthetic spread, we will define a standard threshold strategy based on deviations from the long-run mean.

Since

\[ S_t\sim\mathcal{N}(\mu,\frac{\sigma^2}{2\theta}) \]

in stationarity, the stationary standard deviation is

\[ \sigma_S=\frac{\sigma}{\sqrt{2\theta}}. \]

For our parameters,

\[ \sigma_S=\frac{1}{\sqrt{4}}=0.5. \]

Define thresholds in terms of stationary standard deviations as follows:

  • Long spread if \(S_t\lt\mu-2\sigma_S\)
  • Short spread if \(S_t\gt\mu+2\sigma_S\)
  • Exit when \(S_t\) returns to \(\mu\)

With our parameters that is:

  • Long spread if \(S_t\lt-1\)
  • Short spread if \(S_t\gt1\)
  • Close position when \(S_t=0\)
