1 Ornstein Uhlenbeck Spread Backtest

In order to show that the OU process can be applied to pairs trading we will first construct a synthetic spread and then move to real life data. For real pairs, we first investigate a linear spread, given two asset price series. We then fit the OU model to the observed spread.

1.1 Backtest on Synthetic Spread

Let us generate an OU process and treat it as if it were an observed spread.

Take \(\theta = 2, \mu = 0, \sigma = 1\).

We will now devise a trading rule. For the synthetic spread, we will define a standard threshold strategy based on deviations from the long-run mean.

In the stationary regime, the OU process has distribution

\[ S_t\sim\mathcal{N}(\mu,\frac{\sigma^2}{2\theta}). \]

Thus in stationarity, the stationary standard deviation is

\[ \sigma_S=\frac{\sigma}{\sqrt{2\theta}}. \]

Define thresholds in terms of stationary standard deviations as follows:

  • Long spread if \(S_t\lt\mu-2\sigma_S\)
  • Short spread if \(S_t\gt\mu+2\sigma_S\)
  • Exit when \(S_t\) returns to \(\mu\)

We use the first 75% of the synthetic OU process as training data to estimate the parameters and will subsequently trade the strategy on the remaining 25% to avoid look-ahead bias.

estimated_params = ou.OUParams(
    theta=result.x[0],
    mu=result.x[1],
    sigma=result.x[2],
)

print(estimated_params)

stationary_std = ou.stationary_std(estimated_params)
upper_threshold = estimated_params.mu + 2 * stationary_std
lower_threshold = estimated_params.mu - 2 * stationary_std

positions = np.zeros(len(test))
position = 0

for i, spread in enumerate(test[:, 0]):
    if position == 0:
        if spread < lower_threshold:
            position = 1
        elif spread > upper_threshold:
            position = -1

    elif position == 1:
        if spread >= estimated_params.mu:
            position = 0

    elif position == -1:
        if spread <= estimated_params.mu:
            position = 0

    positions[i] = position

spread = test[:, 0]

pnl = positions[:-1] * np.diff(spread)
cumulative_pnl = np.cumsum(pnl)

trade_pnls = []
in_trade = False
trade_pnl = 0.0

for i, position in enumerate(positions[:-1]):
    if not in_trade and position != 0:
        in_trade = True
        trade_pnl = pnl[i]

    elif in_trade and position != 0:
        trade_pnl = pnl[i]

    elif in_trade and position == 0:
        trade_pnls.append(trade_pnl)
        in_trade = False
        trade_pnl = 0.0

number_of_trades = len(trade_pnls)
winning_trades = sum(trade_pnl > 0 for trade_pnl in trade_pnls)
if number_of_trades > 0:
